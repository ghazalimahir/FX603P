Cara guna

Tulisan kuning di atas butang ialah fungsi SHIFT, biru ialah 2ndF, hijau ialah mod BASE-N, dan huruf merah ialah aksara ALPHA.

+ · −COMP · BASE-NKiraan biasa / HEX, DEC, OCT, BIN

Menulis dan menjalankan program

MODE 2, pilih P0–P4 (SHIFT untuk P5–P9, P1_ + digit untuk P10–P19), tekan langkah-langkahnya, kemudian MODE 1. Tekan P0 untuk menjalankan. HLT berhenti untuk input; masukkan nombor dan tekan EXE. Dalam WRT, BST/FST bergerak antara langkah dan C memadam satu langkah.

Contoh x² + 1: MODE 2 · P0 · HLT · SHIFT MR (x²) · + · 1 · = · MODE 1. Kemudian P0 · 3 · EXE → 10.

Memori

Min, MR, M+, M−, X↔M diikuti dua digit (00–99). Satu digit + EXP memilih daftar F (0F–9F). Statistik: M07 Σx², M08 Σx, M09 n.

Papan kekunci komputer

Digit, + − * / . ( ), Enter = EXE, = , Backspace = C, Esc = AC, s = SHIFT, f = 2ndF, a = ALPHA, m = MODE.

Diagnostik

Tiada ralat direkod.
